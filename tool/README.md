# kabu — 株式相談ツール

日本株の運用を、**相談・記録・調査・レポート**の4つでまわす道具。
Python 3 の標準ライブラリだけで動く(インストール不要)。

```bash
python3 tool/kabu.py <コマンド>
```

短くしたいなら:

```bash
alias kabu='python3 ~/kabu-report/tool/kabu.py'
```

---

## 何をする道具か

手でやっていて事故が起きた場所を、機械にやらせる。

| 手でやっていたこと | 起きた事故 | ツールでどうなるか |
|---|---|---|
| トレーリング逆指値の段を暗算 | 引き上げ忘れ | `morning` が到達した段と引き上げ後の確保額を出す |
| 総リスクを電卓で合計 | 集計漏れ | `risk` が口座比%と上限までの余地を出す |
| 保有表を HTML で手書き | 「出口」欄が空白のまま放置 | 保有表は記録から描かれるので、書き忘れという形が無い |
| 逆指値を切り下げてしまう | ルール⑩違反 | `stop` が切り下げを**拒否**する(`--force` で押し切れるが日記に残る) |
| ポータルのメタを手で揃える | タイルが黙って消える | 未登録の verdict / セクターは**ビルドが止まる** |
| 公開レポートに私的情報が混ざる | ポジションが公開される | `check` が公開物を検査し、`publish` は落ちたら commit しない |

**ツールは判断しない。** 数字を出すところまでで、そこから先は相談で決める。

## 最初の1回

```bash
# 既存の trade_diary.html から取り込む
python3 tool/migrate.py ~/kabu/trade_diary.html --year 2026 --claude-md ~/kabu/CLAUDE.md

# または、まっさらから始める
python3 tool/kabu.py init --cash 655247
```

移行で入るのは保有・取得単価・逆指値・口座の数字・日次カード・ルールブック。
**逆指値の期限と執行方法は日記に書かれていないので入らない。**
証券口座を見て `kabu stop` で補う。

## コマンド

### 相談する

| | |
|---|---|
| `brief` | 相談用の事実シート(Markdown)。**まずこれ** |
| `status` | 口座の要約 |
| `holdings` | 保有一覧。段の到達とバンド判定つき |
| `risk` | ⑫ 全逆指値が同時発動したときの合計と、上限6%までの余地 |
| `ladder [コード]` | ⑩ 段の計算と「先に計算しておく段」の表 |
| `morning [--ok コード...]` | ⑨ 朝のチェック。生存・段・バンド・総リスク・集中度を一度に |

### 記録する

| | |
|---|---|
| `prememo <コード> <価格>` | ⑧ 買う前メモ。未記入の項目は対話で聞く |
| `buy <コード> <株数> <価格>` | ④⑤⑧⑮を当ててから記録。違反があれば止まる |
| `sell <コード> <株数> <価格>` | ⑯(残りの逆指値の確認)と⑱(再エントリー手順)を出す |
| `stop <コード> <価格>` | 引き上げ。**切り下げは拒否** |
| `price 7011=4256 3402=1355` | 現在値の更新 |
| `theme <コード> <テーマ>...` | ⑥ 集中判定用のタグ。引数なしで集中度を見る |
| `frame <コード> <枠>` | ① 枠の変更(原則禁止。記録が残る) |
| `note "タイトル" "本文"` | 日記に1件 |
| `watch` / `earnings` / `account` | ウォッチリスト・決算予定・現金余力 |

枠は `long`(長期)/ `swing`(スイング)/ `hands_off`(触らない)。
枠は「持つ期間」ではなく**出口の決め方**の区分。

### 調べる

| | |
|---|---|
| `research <コード>` | 一次資料から順に集めるチェックリスト |
| `sweep <コード>` | ⑱ 切られたときのニューススイープ(4方向) |
| `decompose <増益額> --item "ラベル=金額"...` | ⑰ 一過性・市況・実質に分解 |

```bash
# IHI: 営業利益732億のうち400億が不動産売却益だった例
python3 tool/kabu.py decompose 458 --item "不動産売却益=400" --prior 274
```

ラベルに「売却益・還付・保険金」等が入っていれば一過性、「市況・為替・在庫・銅価」等が
入っていれば市況として分類する。**残余は実質に寄せる**(実質を過大評価しないため)。

### レポートと公開

| | |
|---|---|
| `report list` | 公開レポート一覧 |
| `report new <コード> --name ... --sector ...` | 9つの節の雛形を作ってメタに登録 |
| `report set <コード> --price ... --verdict ...` | メタの更新 |
| `portal [--asof 2026/8/13]` | `index.html` を生成 |
| `check` | 🔒 プライバシー検査 + メタ整合性検査 |
| `render [diary\|performance\|all]` | 私的HTMLを生成 |
| `publish [--push] [-m メッセージ]` | 生成 → 検査 → commit → push |

## ルールの数値を変えるとき

`tool/kabulib/config.py` だけを直す。段の分数も、バンドの幅も、6%の上限もそこにある。
コードの他の場所に数値を書かない。

```python
R10_LADDER = [                       # (含み益の閾値, 利益に掛ける分数, 段の名前)
    (0.25, 0.75, "第5段 +25%(3/4)"),
    (0.15, 2 / 3, "第4段 +15%(2/3)"),
    (0.10, 0.50, "第3段 +10%(1/2)"),
    (0.05, 0.00, "第2段 +5%(建値)"),
]
R10_BAND = (0.04, 0.10)              # 現在値から何%下に置くか
R12_TOTAL_RISK_MAX = 0.06            # 総リスクの上限(総資産比)
```

変えたらテストを回す:

```bash
python3 -m unittest discover -s tool/tests
```

## 逆指値の丸め

呼値には**切り捨て**で寄せる(1,000円以上は1円、未満は0.1円)。
切り上げると逆指値が現在値に近づいて、通常のノイズで切られやすくなるため。

## 現在値が無いとき

損益ゼロ(取得単価と同じ)として扱う。`price` を回していない銘柄が
含み益ゼロで出てくるのはそのため。
