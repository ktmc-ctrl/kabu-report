# ルールブック

`kabu render diary` がこれを読んで日記に描く。直すならこのファイルを直す。
既存の trade_diary.html があるなら `python3 tool/migrate.py` が全条を取り込む——
これは、まっさらから始めるときの骨組み。

数値そのもの(段の分数・帯の幅・上限%)は `tool/kabulib/config.py` が正で、
ツールはそちらを見て計算する。ここは**なぜそうするか**を書く場所。

---

## 入る前

- **①枠を先に決める** — 買う前に枠(長期 / スイング / 触らない)を決める。あとから変更禁止。
  正直に決めること。「上がりそうだから買う」ならスイング。
- **⑧買う前メモ** — thesis・出口・リスク・承知点・話が別になる条件を書いてから注文する。
  有効期限は**株価が5%動くか3営業日**。古いメモで買うのは、メモなしより危ない。
  → `kabu prememo <コード> <価格>`

## どれだけ持つか

- **⑤サイズ(リスク)— こちらが本命** — 1回で失う額を総資産の**1.5%**に固定する。
  大事なのは「いくら使うか」ではなく「**いくら失うか**」。
  値動きの荒い銘柄は損切りを広げて、その分サイズを小さくする。
- **④サイズ(金額)** — 損切りが置けない/不明確なときのデフォルト上限。
  1銘柄の上限**15%**は常に適用。
- **⑥テーマ集中** — 1テーマは総資産の**3〜4割**まで。同じ船に乗る銘柄は合算で数える。
  → `kabu theme <コード> <テーマ>`
- **⑫総リスク上限** — 全逆指値が同時発動したときの合計損失を総資産の**6%**以内に。
  「何銘柄買ったか」でも「今日いくら使ったか」でもなく、**「全部外れたらいくら失うか」**で管理する。
  → `kabu risk`

## 出口

- **⑨逆指値の毎朝チェック** — 全銘柄に逆指値が生きているか。これが1日の最初のタスク。
  期限は「無期限」、執行方法は必ず「**成行**」(指値だとギャップで売れ残る)。
  → `kabu morning`
- **⑩トレーリング逆指値(5段ラダー)** — 売らずに利益を確保する唯一の仕組み。
  株価が上がるたびに切り上げ、**下がった時は絶対に切り下げない。**
  決めているのは分数ではなく「現在値から何%下に置くか」で、守りたいのは**4〜10%の帯**。
  値動きの荒い銘柄は計算値ではなく**直近の押し安値の下**を優先する。
  → `kabu ladder <コード>`
- **⑯一部売却したら、必ず逆指値を確認する** — 一部を売ると残りの分の逆指値まで
  取り消されることがある。「半分売ってリスクを減らしたつもりが、出口がなくなっていた」が最悪。

## 買い増し

- **⑮ピラミッディング** — ①第1回が+5%以上乗ってから ②追加は第1回と同じ株数まで、上限2回
  ③追加したら逆指値を新しい平均取得単価の下へ引き上げる。
  ④下がってからの買い増しはこれに該当しない(それはナンピン)。

## 下がったとき

- **⑬下げてる銘柄は「なぜ」を先に確認** — 決算が理由なら初日に飛びつかない。
  相場につられただけなら押し目として検討可。
- **⑭押し目の判定は底打ちと別基準** — 底打ち3条件(安値切り上げ・5日線の上・高値から20%調整)は
  下降トレンドの終わり。上昇トレンド中の押し目は4条件(トレンド継続・押しが浅い・
  支持線で止まる・出来高が減りながら下げている)。
- **⑱コア銘柄の再エントリー** — 発動=撤退ではなく「現金化して再検証に入る合図」。
  ニューススイープ → thesis の生死 → 底打ち/押し目 → 新しい買う前メモ の順。
  **「話が別になる条件」が出ていたら再エントリー禁止。切られた値段は忘れる。**
  → `kabu sweep <コード>`

## 分析

- **⑰増益率は必ず中身を分解する** — 見るのは3つ。①一過性利益が入っていないか
  ②受注高はどうか ③営業キャッシュ・フローはついてきているか。
  **中身が悪い会社と、良いのに期待が高すぎた会社は、まったく別物として扱う。**
  → `kabu decompose`
- **⑪決算** — 長期枠はまたぐ。スイング枠は原則またがない、またぐなら量を半分に。
  **決算ギャップは逆指値で防げない。**−15%で寄り付けば−5%の逆指値は寄り付き価格で約定する。
  防ぐ方法は「持たない」か「量を減らす」だけ。
