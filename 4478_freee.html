サマリー

中小企業・個人事業主のクラウド会計・人事労務SaaS。2026年6月期通期(8/13発表)は売上424.4億円(+27.6%)・営業利益10.9億円と2期連続の営業黒字で拡大、ARRは435.9億円(+21.8%)。データ資産は有料69.4万事業者の会計・人事データと、freeeアドバイザー5,500事務所超(大手100会計事務所のうち81社)という税理士ネットワークの二層構造。2026年は「AIから最も使いやすいSaaS」を掲げてMCPサーバー(3月)・会計事務所向けAIエージェント基盤「freee Agent Hub」(8/28正式版)・顧問先管理AIエージェント(9/15予定)を矢継ぎ早に投入し、2月には「AIがSaaSを代替する」懸念で年初来安値まで売られた会社が、「AIの実装者」側として半年で株価2倍になった。決算と同時に発表した初の自社株買い50億円で8/14はストップ高。ただし純利益ベースの会社予想は非開示で、実績PERは約210倍・PBR10.7倍——利益はまだ「調整後」の世界にある——評価: PER非適用。

データ資産とAI — 「AIから最も使いやすいSaaS」

二層のデータ・ネットワーク:
・69.4万事業者の会計・人事データ(法人27.5万+個人42.0万)。日々の仕訳・請求・給与がリアルタイムに流れ込む
・freeeアドバイザー5,500事務所超。国内大手100会計事務所のうち81社が加入。アドバイザー併用顧客の解約率は約40%低い——士業ネットワークが解約の防波堤になっている

AI施策(すべて一次資料で日付確認):
・freee-mcp(MCPサーバー): 2026年3月。Public API 380本超を生成AIに開放。共同創業者CTOがCAIO(AI最高責任者)に就任
・freee Agent Hub(会計事務所向けAIエージェント基盤): 2026年4月発表→8月28日正式版
・freee顧問先管理AIエージェント(資料回収〜決算申告を一気通貫): 8月7日発表、9月15日提供開始予定
・freee AIアシスタント(法人向け、6月β)、AIファイル自動記帳ほか

注目は方向性: 自社アプリにAIを足すだけでなく、「税理士がAIで顧問先を回すための基盤」を握りにいっている。会計事務所がfreeeのエージェント上で仕事をするほど、実務データとワークフローの両方がfreeeに蓄積する——弁護士ドットコムがLegalBrainでやっている構図の会計版。

リスク要因(注視点)

・利益の実額はまだ薄い: 会計上の営業利益率2.6%。成長の議論が「調整後」指標に依存
・純利益は税効果で振れる(今期の▲21.3%がその例)
・短期借入が96億→143億円に増加。フィンテック関連(立替金・債権買取)の資金需要が膨らむ
・マネーフォワード・弥生との競争。A-SaaS終了に伴う一時的なユーザー純増減
・強気材料の裏返し: 2月の急落(高値からほぼ半値)は「汎用AIが記帳を無料でやる世界」への恐怖だった。AIの実装者側に回る戦略が効いている間は追い風だが、この論争は今後も株価を大きく振らす
